# ไฟล์เสียงของเกม BAAN PAIBOON

วางไฟล์ตามชื่อด้านล่างในโฟลเดอร์นี้ เกมจะเล่นอัตโนมัติ ไม่ต้องแก้โค้ด
(รองรับ .mp3 — ถ้าจะใช้นามสกุลอื่น ให้แก้ชื่อไฟล์ใน `src/game/content/soundscape.ts`)

ถ้ายังไม่มีไฟล์: เสียงที่มีเครื่องหมาย ✦ เกมจะสังเคราะห์เสียงแทนชั่วคราว ส่วนที่เหลือจะเงียบ

## เสียงร้องสัตว์เลี้ยง (เล่นตอนนั่งรอเป็นครั้งคราว และตอนลุกวิ่งตาม)

เช่น pet-dog-1.mp3 (โฮ่ง หมาใหญ่), pet-dog-2.mp3 (บ็อก), pet-dog-3.mp3 (แง่ง หมาเล็ก), pet-dog-4.mp3 (หอน)
