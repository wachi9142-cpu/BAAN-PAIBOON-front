# บ้านตารัง–ยายเลียน (จุดเริ่มต้นของเกม)

> เอกสารอ้างอิงสำหรับทีมพัฒนา — เรียบเรียงจากความทรงจำของผู้สร้างเกม
> ข้อมูลส่วนหนึ่งได้จากการสอบถาม แม่ น้า ยาย และผู้ที่เกี่ยวข้องในหมู่บ้าน
> **ยังมีรายละเอียดอีกมาก จะเพิ่มต่อภายหลัง** — ส่วนที่ยังไม่รู้ให้ทำเครื่องหมาย ❓ ไว้

---

## 0. ความหมายของบ้านหลังนี้

บ้านไพบูลย์เป็น **เกมจำลองภาพความทรงจำของผู้สร้าง** ผู้สร้างอยากให้ทุกคนได้รู้จัก

- เพื่อนบ้านที่น่ารัก
- ความน่ารักและความอบอุ่นของบ้าน
- ชาวบ้าน บรรยากาศ ประเพณี อาชีพ และกิจกรรมของคนในหมู่บ้าน

> "ขอบคุณที่เข้ามาเล่นเกมในความทรงจำ — ความทรงจำที่มีตายายอาศัยและยังมีชีวิตอยู่"
> (ใช้เป็นข้อความขอบคุณในเกม เช่น หน้าเครดิต หรือตอนเริ่มเกมครั้งแรก)

**ผู้เล่นเริ่มต้นเกมที่บ้านหลังนี้**

## 1. ตัวบ้านหลัก — บ้านไม้สองชั้น พื้นปูน

### 1.1 ชั้น 2

| ส่วน | รายละเอียด |
|---|---|
| ผัง | ห้องนอน 3 ห้อง อยู่ **ทางขวามือ** · **ทางซ้ายมือ** เป็นแนวหน้าต่างคู่ รวม **8 บาน** |
| ห้องนอนที่ 1 | ห้องแรกที่ขึ้นบันไดมาถึง · หน้าต่างที่หัวนอน **4 คู่** · หน้าต่างด้านขวาอีก **4 คู่** |
| ห้องนอนที่ 2 | เปิดประตูเข้าไป · หน้าต่างที่หัวนอน **4 คู่** |
| ห้องนอนที่ 3 | หน้าต่างที่หัวนอน **4 คู่** · หน้าต่างด้านซ้ายอีก **4 คู่** |
| กลางบ้านชั้น 2 | มี **โทรทัศน์** |

### 1.2 ชั้น 1 (เดินตามลำดับจากบันได)

1. **บันได** — ลงจากชั้น 2 ประมาณ **30 ขั้น**
2. ลงมาแล้ว **หันซ้าย** → **ตู้เสื้อผ้ายายเลียน**
3. ถัดไป → **ห้องน้ำ**
   - ชักโครก · กระจก · ฝักบัวอาบน้ำ · **เครื่องซักผ้า 2 ตู้** · ราวแขวนติดกำแพง
   - ผนังเป็น **ลายสีฟ้า-ขาว**
   - ชั้นวาง: สบู่ แชมพู แก้วแปรงสีฟัน ยาสีฟัน ครีมอาบน้ำ
4. ถัดจากห้องน้ำ → **หน้าต่างบานใหญ่ 2 บาน** มี **ผ้าม่านสีขาวปลิวไปมา**
5. → **เตียงนอนของยายเลียนกับตารัง** มีกำแพงกั้น
6. ถัดไป → **ห้องน้ารง** (น้าชายคนที่สองของบ้าน)
   - หน้าห้องมี **ตู้เสื้อผ้าใหญ่ 3 ประตู** มีลิ้นชัก มีกระจก
   - **หลังตู้เสื้อผ้า = ที่เลี้ยงหนอนไหมของยายเลียน** 🐛
7. กำแพงถัดจากเตียงตารัง → **หน้าต่างสแตนเลสมุ้งลวด ยาวครึ่งบ้าน**
8. ถัดจากที่นอนตารัง → **ตู้เสื้อผ้าหันหน้าเข้าเตียงตารัง**
9. ถัดจากตู้เสื้อผ้า →
   - **เปลนั่งนอน** — ตาชอบนั่งชมวิวตอนเช้า
   - **เครื่องจักรทำผ้าไหมของยายเลียน**
10. **ประตูเปิดออกไปนั่งชมวิว**
11. ถัดจากประตู → **สแตนเลสมุ้งลวดยาวต่อเนื่องไปจนถึงห้องครัว**
12. **ห้องครัว** — มีประตูเปิดออกไปด้านนอก
13. **กลางบ้าน** (มองจากห้องครัวออกมา)
    - **ทีวีจอใหญ่** ตั้งด้านบน · **ลำโพงเครื่องเสียงประกบซ้าย-ขวา**
    - **โซฟาไม้ขัดเงาสีน้ำตาลสวย** · เก้าอี้ไม้สัก (2 ตัว)
    - โต๊ะวางของและขนม
    - ตู้ชั้นวางเครื่องเล่น DVD / CD
    - 💛 เด็ก ๆ ในบ้าน รวมถึงผู้สร้าง **ชอบแย่งกันนั่ง แย่งกันนอนโซฟาไม้ตัวนี้มาก**
14. ถัดจากห้องครัว → **แคร่ขนาดใหญ่ 2 ตัววางติดกัน** ไว้วางของ
15. ถัดจากแคร่ → **ประตูบ้านสีน้ำเงินบานใหญ่** มีสแตนเลสมุ้งลวดมองออกไปได้
16. หน้าประตู → **แคร่อีกตัว = ที่นอนของน้องหมา 4 ตัว**
17. มี **รถยนต์จอดอยู่ 1 คัน**

## 2. รอบบ้าน (พื้นที่ภายนอก)

### 2.1 หลังครัว
- ยืนในห้องครัว หันหลังให้คนในบ้านมองออกไป → **โอ่งใหญ่ใส่น้ำ** และ **โอ่งรองน้ำฝน**
- ถัดจากโอ่ง → **สวนผักสวนครัว** และ **สวนดอกไม้ของยายเลียน**

### 2.2 สวนผลไม้ (หน้ารั้วสวนผัก — ตายายปลูกร่วมกัน)

| ต้นไม้ | จำนวน | หมายเหตุ |
|---|---|---|
| น้อยหน่า | 3–4 ต้น | |
| มะพร้าว | 3–4 ต้น | |
| ขนุน | 2 ต้น | |
| ใบเตย | 5–6 ต้น | |
| ชมพู่แคระ | 4 ต้น | ต้นเตี้ย |
| มะม่วงแคระ | 2 ต้น | **ปีนขึ้นไปเล่นได้** |
| มะม่วงต้นใหญ่ | 3–4 ต้น | ลำต้นไว้ **ผูกเปล** |
| หมาก | 50 กว่าต้น | |
| กล้วย | 10 ต้น | |

### 2.3 ฝั่งซ้ายของสวนผัก (ยืนหันหน้าเข้าสวนผัก) — เรียงตามลำดับ
1. **ยุ้งข้าวโบราณ** 1 หลัง
2. **บ้านหลังที่สอง** ไว้ทำกับข้าว — 💛 ผู้สร้างชอบมานอนที่บ้านหลังนี้มาก
   - **ใต้ถุน** = ที่เก็บเครื่องมือทำสวน และซ่อมรถของน้ากับตารัง
3. **ห้องน้ำนอกบ้าน 2 ห้อง**
   - ห้องที่ 1: ห้องอาบน้ำอย่างเดียว
   - ห้องที่ 2: มี **ชักโครกคอห่าน**
4. ข้างห้องน้ำ (หันหน้าเข้าห้องน้ำ → ด้านซ้าย) → **คอกควาย** 🐃 ควาย 5 ตัว
   - แม่ควาย 2 ตัว
   - ลูกควายเพศผู้ ตัวโต 1 ตัว
   - ลูกควายเพศเมีย ตัวเล็ก 1 ตัว
   - ลูกควายเพศเมีย **เพิ่งคลอดได้ 2 เดือน** 1 ตัว
5. **เล้าไก่** (ไก่บ้าน 1 เล้า) · บนคานก่อนหลังคาเล้าควาย มี **รังแม่ไก่ตามมุมเสา**
6. **คอกหมู**
7. **ยุ้งเก็บฟางให้ควาย**
8. ถัดไป → **พื้นที่มีหญ้าแซม ๆ**

### 2.4 ต้นไม้รอบบ้าน

| ต้นไม้ | จำนวน | ตำแหน่ง |
|---|---|---|
| หมาก | 40 กว่าต้น | พื้นที่หญ้า |
| มะพร้าว | 25 ต้น | รอบบ้าน |
| ไผ่ | 10 กอใหญ่ | |
| มะม่วงเขียวใหญ่ | 4 ต้น | |
| ลำไย | 1 ต้น | กลางรั้วบ้าน |
| ลำไย | 2 ต้น | หลังห้องน้ำ 2 ห้อง |
| ยอ (มีลูกยอ) | 4 ต้น | |
| กล้วยไม้ | 10 ต้น | **เรือนกล้วยไม้หน้าบ้านฝั่งครัว** — ยายชอบมาก |
| แก้วมังกร | 3 ต้น | |

### 2.5 อื่น ๆ
- หลังแนวมะพร้าวรอบบ้าน → **รั้วไม้รอบบ้าน**
- หน้าบ้าน → **เครื่องกรองน้ำ** ที่เจาะจาก **น้ำบาดาล**

## 3. คนในบ้าน และกิจวัตร

### รูปร่างหน้าตา (ใช้ทำโมเดลตัวละคร)

| | ตารัง | ยายเลียน |
|---|---|---|
| อายุในเกม | **68 ปี** | **60 ปี** (ให้คงอายุนี้ไว้) |
| ส่วนสูง | **157 ซม.** | **158 ซม.** (สูงกว่าตาเล็กน้อย) |
| รูปร่าง | สูง ผอม | ตัวเล็ก ผอมเพรียว |
| ผม | ดำทั้งหัว มีผมขาวแซม | ขาวเกือบทั้งหัว มีสีดำแซม |

### ตารัง
- **เช้ามืดตีสี่** พา **ควายไปไว้ที่นา**
- กลับบ้านมา **ช่วยยายเลียนทำกับข้าว** — ให้ตัวเอง · ให้พระ · ให้ข้าวหมาและไก่
- จากนั้น **เดินไปวัดในหมู่บ้าน** (ใส่บาตร)
- ชอบนั่ง **เปลชมวิวตอนเช้า**
- ซ่อมรถ/เก็บเครื่องมือที่ใต้ถุนบ้านหลังที่สอง (ร่วมกับน้า)

### ยายเลียน
- ชอบ **รดน้ำต้นไม้ ปลูกผัก ปลูกดอกไม้** · รักเรือนกล้วยไม้มาก
- **ช่วงสาย ๆ** เข้ามาในบ้าน นั่ง **ถักไหมพรม** ทำ **หมวก กระเป๋า ตุ๊กตา**
- **เลี้ยงหนอนไหม** (หลังตู้เสื้อผ้าน้ารง) และมี **เครื่องจักรทำผ้าไหม** → เชื่อมกับอาชีพ "เลี้ยงไหมและผลิตผ้าไหม"
- ทำกับข้าวกับตารังทุกเช้า

### น้ารง
- น้าชายคนที่สองของบ้าน มีห้องนอนชั้น 1

❓ คนอื่นในบ้าน (แม่ น้าคนอื่น เด็ก ๆ) — รอข้อมูลเพิ่ม

## 5. นำไปทำในเกมอย่างไร (ข้อเสนอสำหรับทีมพัฒนา)

## 6. ข้อมูลที่ยังขาด (ถามผู้สร้างเพิ่ม)
- ชื่อหมาตัวที่ 5 · เพศ/อายุของโซดา
- ตำแหน่งบ้านในหมู่บ้าน (ใกล้วัด? ใกล้ทุ่งนา?) และระยะทางไปนาที่ตาพาควายไป
- คนอื่นในบ้าน (แม่ น้าคนอื่น ๆ) และกิจวัตร
- เสื้อผ้าที่ตารัง ยายเลียน ใส่ประจำ · ทรงผมยาว/สั้น · หน้าตาน้ารง
- สีและวัสดุของบ้าน (สีไม้ สีหลังคา) · มีรูปถ่ายอ้างอิงไหม
