# เสาหลักของบ้านไพบูลย์ (Paiboon Village)

> เอกสารนี้คือ "จุดคงที่" ของเกม — ทุกครั้งที่มีไอเดียใหม่ ให้กลับมาดูหน้านี้ก่อนว่ามันช่วยเสาหลักไหม
> ตกลงกับผู้สร้าง 19 พ.ย. 2569 (ฉบับที่ 2: 5 เสาหลัก) · แก้ได้เสมอ แต่ควรแก้ที่นี่ก่อนแก้ในเกม

## 1. ตัวตนของเกม

**ชื่อเกม:** บ้านไพบูลย์ (Paiboon Village)
**แนวเกม:** Open World Adventure + Thai Folklore + Survival + Sandbox

> เกมผจญภัยในโลกเปิดที่ผู้เล่นออกเดินทางสำรวจดินแดนอันกว้างใหญ่ ค้นพบสถานที่ใหม่ สิ่งมีชีวิตที่ไม่เคยพบ ทรัพยากรล้ำค่า และความลับที่ซ่อนอยู่ในโลก
> พร้อมสร้างบ้าน ฐานที่พัก และพัฒนาตัวเองเพื่อเดินทางไปได้ไกลกว่าเดิม

**แกนหลัก: ผจญภัยในโลกชนบทไทยที่มีความเชื่อและเรื่องราวลี้ลับ**
ไม่จำเป็นต้องเป็นแฟนตาซีเต็มรูปแบบ และไม่จำกัดอยู่แค่การทำไร่ทำนา — โลกนี้มีทั้งสิ่งที่พบเห็นได้ในชีวิตจริง และสิ่งที่ชาวบ้านเล่าขานกันมาหลายชั่วอายุคน

**หมู่บ้านไพบูลย์ = จุดเริ่มต้นและหนึ่งในสถานที่สำคัญของโลก ไม่ใช่ขอบเขตทั้งหมดของเกม**
(บ้านตารัง–ยายเลียนคือบ้านแรกและฐานแรกของผู้เล่น)

### โลกของเกมมี 2 ด้าน — แต่เป็นโลกเดียวกัน

| ด้านที่หนึ่ง: โลกชีวิตจริง | ด้านที่สอง: โลกความเชื่อและสิ่งลี้ลับ |
|---|---|
| หมู่บ้านและชุมชนชนบทไทย | ผีป่า ผีบ้านผีเรือน เจ้าป่าเจ้าเขา |
| ป่า ภูเขา แม่น้ำ ทุ่งนา | ศาลเก่า สถานที่ศักดิ์สิทธิ์ ปริศนา |
| เกษตร เลี้ยงสัตว์ หาของป่า | พญานาคและสัตว์ในตำนาน |
| วิถีชีวิตและภูมิปัญญาท้องถิ่น | เครื่องราง ของขลัง พิธีกรรม (ในโลกเกม) |
| การค้าขายและแลกเปลี่ยนสินค้า | พื้นที่ลึกลับที่ไม่ใช่ทุกคนจะค้นพบได้ |

**กติกา:** สองด้านซ้อนอยู่ในแผนที่เดียวกัน ไม่แยกเป็นเกมหรือโหมดต่างหาก ด้านลี้ลับจะ "โผล่" ออกมาจากที่ธรรมดา เช่น
- ศาลเก่าในป่า ซึ่งตอนกลางวันเป็นแค่ศาลร้าง
- สระในถ้ำที่พญานาคอาศัย
- ทางเข้าที่เห็นได้เฉพาะตอนกลางคืน หรือเมื่อพกเครื่องราง

ความเชื่อท้องถิ่นใช้แบบให้เกียรติ เป็นเรื่องเล่าในโลกเกม ไม่ล้อเลียนศาสนา

### ภาพที่ผู้สร้างอยากเห็น (เล่าเอง 19 พ.ย. 2569)
เดิมตั้งใจทำเกมจำลองชีวิตชนบท แล้วอยากให้เกม "ว้าว" และหลากหลายขึ้น (ตอนนี้คนทำเกม AI กันเยอะ) แต่**คงคอนเซ็ปต์เดิม**: หมู่บ้านไพบูลย์และวิถีชีวิตที่ผู้สร้างรัก

**ในหมู่บ้าน: ชีวิต อาชีพ ความเชื่อ การแปรรูป**
- เส้นทางไหม: เลี้ยงหนอนไหม → ดักแด้ → สาวไหม → ทอผ้า → ผ้าถุง / เสื้อ
- สานตะกร้า งานฝีมือ วิถีชีวิตคนในชุมชน
- **บอร์ดภารกิจที่รับงานได้จริง** · เดินไปคุยกับพ่อค้าแม่ค้าและชาวบ้าน "มีเรื่องให้ช่วยไหม" → รับภารกิจไปทำ

**ออกจากหมู่บ้าน: เดินต่อไปเรื่อย ๆ ผจญภัย**
- อาวุธและของขลัง: ดาบ หอก ธนู ยันต์ สายสิญจน์
  - ดาบ (หอก ธนู) ใช้สู้กับโจร
  - ยันต์และสายสิญจน์ใช้กับผี
- หากินข้างทาง: เก็บหญ้า ใบไม้ ทุบตีต้นไม้ได้กิ่งและท่อนไม้ · วัตถุดิบเอาไปทำอาหาร ทำเสื้อ
- สัตว์หายาก ง่าย → ยาก: มี**รูปเพชรสีบนหัวสัตว์**บอกระดับ · แต่ละชนิดจับคนละวิธี · จับแล้วเอาไปกิน ใช้งาน หรือใช้ต่อสู้
- **ไม้คฑาอาจเอาออก** แล้วเปลี่ยนเป็นวิธีจับแบบอื่นที่เข้ากับโลกไทยมากกว่า (ยังไม่ตัดสินใจ — รอคุยกัน)

## 2. วงจรหลัก (Core Loop)

```
ออกเดินทาง ─► สำรวจ/ผจญภัย ─► ค้นพบ (ที่ใหม่ สัตว์ ทรัพยากร ความลับ) ─► กลับฐานมาประดิษฐ์/พัฒนา ─► ไปได้ไกลกว่าเดิม
     ▲                                                                                              │
     └──────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 3. ห้าเสาหลัก

| เสาหลัก | เป้าหมาย | มีแล้วในเกม |
|---|---|---|
| **สำรวจโลก** | มีสถานที่ใหม่ให้ค้นพบอยู่เสมอ | หมู่บ้าน + สถานที่ที่ค้นพบ · ถ้ำน้ำลึก (โซนรอบนอกแห่งแรก) · ดำน้ำ |
| **ผจญภัย** | มีอุปสรรค ความท้าทาย และการค้นพบ | หีบสมบัติลับในป่า · ลมหายใจใต้น้ำ · ตกน้ำ/หมดแรง · วงล้ออาวุธ · ต่อยมือเปล่า |
| **สิ่งมีชีวิต** | พบสัตว์ทั่วไป สัตว์หายาก และสัตว์วิเศษ | สัตว์ป่าระดับง่าย–ยาก จับด้วยคฑา · ประเภทสัตว์ 6 หมวด · มังกรน้ำ พญานาค · ทีมสัตว์ + ความผูกพัน |
| **พัฒนาและเอาตัวรอด** | เก็บทรัพยากร ประดิษฐ์อุปกรณ์ พัฒนาความสามารถ | เก็บไม้/หิน/เชือก · ประดิษฐ์เครื่องมือ · อานสัตว์ · หมวกฟองอากาศ · ค่าหิว/กระหาย/สุขภาพ · กระเป๋าขยายได้ |
| **สร้างโลกของตัวเอง** | มีบ้าน ฐานพัก และพื้นที่ส่วนตัว | สร้าง/วางสิ่งปลูกสร้าง · ย้ายของในบ้าน · บ้านเดินเข้าได้ นอน ทำอาหาร |

## 4. เอกลักษณ์ของบ้านไพบูลย์

**องค์ประกอบหลัก**
- หมู่บ้านชนบทไทยและวิถีชีวิตผู้คน
- ป่า ภูเขา ถ้ำ ลำธาร และพื้นที่ห่างไกล
- **ความเชื่อท้องถิ่น ตำนาน และเรื่องเล่าลี้ลับ** (เช่น พญานาค ผีเฝ้าป่า ศาลปู่ตา เรื่องเล่าผู้เฒ่า — ยังไม่ได้ทำ)
- สัตว์ป่าและสัตว์ที่เกี่ยวข้องกับตำนาน
- การเดินทาง สำรวจ เก็บทรัพยากร และเอาตัวรอด
- การสร้างบ้านและพื้นที่พักพิงระหว่างการเดินทาง

**ระบบเสริม** (อยู่ได้ แต่ต้องสนับสนุนเสาหลัก ไม่แย่งตำแหน่งแกนหลัก)
- ร้านค้าและการแลกเปลี่ยน (ความซื่อสัตย์แบบ C — อนาคต)
- การทำอาหารและเกษตรกรรม
- การเลี้ยงสัตว์ (คอก วงจรนอน อุ้ม)
- เทศกาลและกิจกรรมในหมู่บ้าน · วัด เซียมซี · เช็กอินรายวัน

## 5. โลก: หมู่บ้าน + ดินแดนรอบนอก (สมมติ)

- **หมู่บ้านไพบูลย์** — จริง แต่ไม่ใส่รายละเอียดแผนที่จริง (ดูข้อตกลงเรื่องความเป็นส่วนตัว)
- **ดินแดนรอบนอก** — สมมติทั้งหมด ขยายทีละโซน แต่ละโซนมีทรัพยากร สัตว์ ตำนาน และความลับของตัวเอง

| โซน | มีอะไร | สถานะ |
|---|---|---|
| ถ้ำและใต้ดิน | แร่หายาก สมบัติ สิ่งมีชีวิตลึกลับ | ✅ ถ้ำน้ำลึกแห่งแรก |
| แม่น้ำและทะเลสาบ / ลำธาร | ดำน้ำ ตกปลา สัตว์น้ำ | 🔶 บ่อในหมู่บ้าน + สระในถ้ำ |
| ป่าลึกลับ | สัตว์ป่า สมุนไพร ทรัพยากร ตำนานผีป่า | ⬜ |
| พื้นที่โบราณ | ความลับ ปริศนา ของสะสม | ⬜ |
| ภูเขา | เส้นทางสูง ทรัพยากรหายาก | ⬜ |

## 6. ระบบอนาคต (จดไว้ ยังไม่ทำตอนนี้)
- ร้านค้าเต็มระบบ + แลกเปลี่ยนสินค้า + ความซื่อสัตย์ (แบบ C: ชื่อเสียงรวม + ความสัมพันธ์รายคน)
- บ้านชาวบ้านหลายชั้น · สัตว์พลังพิเศษเพิ่ม · สัตว์ดึกดำบรรพ์
- ผู้เล่นหลายคน/เซิร์ฟเวอร์ (เกมตอนนี้เล่นคนเดียว เซฟในเครื่อง — งานคนละระดับ)

## 7. กติกากันไหล
1. ไอเดียใหม่ → จดใน `docs/IDEAS.md` ก่อน พร้อมป้าย **เสาหลัก / เสริม / อนาคต**
2. งานถัดไปเลือกจากสิ่งที่ช่วย **5 เสาหลัก** ก่อนเสมอ
3. ระบบเสริมทำได้เมื่อช่วยเสาหลักชัด ๆ (เช่น ร้านหน้าบ้าน = ขายของที่ไปเก็บมาจากการผจญภัย)
4. แก้หน้าตา/ย้ายของในหมู่บ้านทำได้ตลอด (ไม่นับเป็นระบบใหม่)

## 8. ก้าวถัดไปที่แนะนำ
1. **ทรัพยากรจากการสำรวจ** — ของที่หาได้เฉพาะโซนรอบนอก (แร่/คริสตัลในถ้ำ ไข่มุกใต้น้ำ สมุนไพรในป่า) ใช้ประดิษฐ์อุปกรณ์ อาน และพัฒนาฐาน
2. **ตำนานและเรื่องเล่า** — ชาวบ้าน (ผู้เฒ่า) เล่าเรื่องลี้ลับที่ชี้ทางไปสถานที่/สัตว์ในตำนาน เช่น เรื่องพญานาคในถ้ำน้ำลึก
3. **โซนป่าลึกลับ** — โซนรอบนอกแห่งที่ 2
4. **ฐานพักระหว่างทาง** — กางที่พัก/ก่อกองไฟนอกหมู่บ้าน พักฟื้น เซฟจุดเกิด
